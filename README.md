# Jafar Khandu — Portfolio

A modern, responsive portfolio for Jafar Khandu, built with React and Vite.

## Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production output is generated in `dist/` and can be served as a static site behind Nginx.

## Notes

The portfolio uses original content and styling inspired by modern developer portfolio patterns. Project descriptions are based on the actual technologies and workflows used in Jafar's projects.

Before final production deployment, add the final resume PDF and professional profile image to the `public/` directory and update the corresponding UI links.
